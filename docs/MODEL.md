# MacroCanvas: спецификация модели

Настоящий документ фиксирует математическую структуру синтетической экономики MacroCanvas, калибровку, свойства стационарности и точное соответствие между процессом порождения данных (DGP) и оцениваемыми уравнениями. Он дополняет раздел 3 README и предназначен для читателя, которому нужны детали, а не обзор.

---

## 1. Область применения и статус модели

MacroCanvas — **полуструктурная** модель малой открытой экономики квартальной частоты. Она соединяет четыре reduced-form блока (IS, кривая Филлипса, закон Оукена, правило Тейлора) в единый рекурсивный DGP. Модель:

- **не** является микрофундированной DSGE;
- **не** предназначена для welfare-анализа;
- **не** оценивается на реальных данных;
- используется как контролируемая среда для проверки эконометрических инструментов и демонстрации полного аналитического цикла.

Ключевое свойство: истинные параметры известны, поэтому любую оценку можно сравнить с истиной, а любую декомпозицию — проверить на точность.

Это делает DGP рекурсивным и исключает одновременность в реальном блоке.

## 3. Полная система

### 3.1. Ожидания и реальная ставка

```
πᵉₜ = ω·π* + (1 − ω)·πₜ₋₁,                       ω = 0.35          (1)
rᵉₜ = iₜ₋₁ − πᵉₜ                                                    (2)
```

Ожидания — выпуклая комбинация цели и фактической инфляции прошлого квартала. Параметр ω управляет степенью заякоренности: при ω = 1 ожидания рациональны и равны цели; при ω = 0 — чисто адаптивны. Значение 0.35 — промежуточный режим, воспроизводящий инерцию инфляции без полной рациональности.

Реальная ставка использует **прошлое** решение по политике `iₜ₋₁`, поэтому политика влияет на спрос с лагом в один квартал.

### 3.2. IS-кривая

```
xₜ = ρₓ·xₜ₋₁ − σᵣ·(rᵉₜ − r*) + δ_f·fₜ + δ_{x*}·x*ₜ − δ_s·sₜ + εˣₜ     (3)
```

| Параметр | Значение | Диапазон допустимых | Экономическая роль |
| --- | --- | --- | --- |
| ρₓ | 0.68 | [0, 1) | инерция спроса |
| σᵣ | 0.20 | ≥ 0 | межвременное замещение |
| δ_f | 0.18 | ≥ 0 | фискальный мультипликатор (приведённый) |
| δ_{x*} | 0.12 | ≥ 0 | открытость экономики |
| δ_s | 0.12 | ≥ 0 | финансовый акселератор (упрощённо) |
| r* | 0.75 | — | нейтральная реальная ставка |
| σ(εˣ) | 0.45 | ≥ 0 | волатильность шока спроса |

**Стационарное состояние:** x = 0 при rᵉ = r*, f = x* = s = 0. Условие затухания автономной динамики: |ρₓ| < 1 (выполнено). Полная система с обратной связью через правило Тейлора стабильна при параметрах baseline — это подтверждается companion-матрицей VAR (максимальный модуль корня 0.844).

### 3.3. Кривая Филлипса

```
πₜ = π* + α·(πₜ₋₁ − π*) + κ·xₜ₋₁ + γ_o·oₜ + ε^πₜ                    (4)
```

| Параметр | Значение | Экономическая роль |
| --- | --- | --- |
| π* | 2.0 | цель и долгосрочный уровень |
| α | 0.58 | инерция / адаптивная компонента |
| κ | 0.25 | наклон по разрыву выпуска (лаг 1) |
| γ_o | 0.015 | перенос нефтяного шока |
| σ(ε^π) | 0.60 | волатильность шока предложения |

**Стационарное состояние:** π = π* при x = o = 0. Условие стабильности: |α| < 1 (выполнено). Использование `xₜ₋₁` вместо `xₜ` устраняет одновременность между выпуском и инфляцией внутри квартала.

### 3.4. Закон Оукена

```
ηₜ = ρ_η·ηₜ₋₁ + ε^uₜ                                                 (5)
uᵍᵃᵖₜ = −β·xₜ + ηₜ                                                    (6)
uₜ = u* + uᵍᵃᵖₜ                                                      (7)
```

| Параметр | Значение | Экономическая роль |
| --- | --- | --- |
| u* | 5.4 | естественная безработица |
| β | 0.42 | коэффициент Оукена |
| ρ_η | 0.50 | персистентность трудового остатка |
| σ(ε^u) | 0.15 | волатильность шока |

Остаток ηₜ серийно коррелирован — это сознательная особенность: она порождает автокорреляцию остатков оценённого уравнения Оукена (ACF(1) ≈ 0.45) и делает HAC-инференцию содержательной, а не декоративной.

### 3.5. Правило Тейлора с нижней границей

```
iᵈᵉˢₜ = r* + π* + φ_π·(πₜ − π*) + φ_x·xₜ                            (8)
iₜ = max{ i_ELB, ρ_i·iₜ₋₁ + (1 − ρ_i)·iᵈᵉˢₜ + ε^iₜ }                 (9)
```

| Параметр | Значение | Экономическая роль |
| --- | --- | --- |
| ρ_i | 0.78 | сглаживание ставки |
| φ_π | 1.45 | реакция на инфляцию (> 1: принцип Тейлора) |
| φ_x | 0.55 | реакция на разрыв выпуска |
| i_ELB | 0.25 | эффективная нижняя граница |
| σ(ε^i) | 0.18 | волатильность шока политики |

Нейтральная номинальная ставка: `r* + π* = 2.75 %`. Принцип Тейлора выполнен: φ_π = 1.45 > 1. Инерция 0.78 означает, что ставка закрывает 22 % разрыва с желаемым уровнем за квартал — примерно половина разрыва за год.

### 3.6. Экзогенные процессы

```
x*ₜ = 0.82·x*ₜ₋₁ + εˣ*ₜ,          εˣ* ~ N(0, 0.90²)                 (10)
fₜ  = 0.55·fₜ₋₁  + εᶠₜ,           εᶠ  ~ N(0, 0.45²)                 (11)
oₜ  = 0.65·oₜ₋₁  + εᵒₜ,           εᵒ  ~ N(0, 4.50²)                 (12)
sₜ  = 0.82·sₜ₋₁  + εˢₜ,           εˢ  ~ N(0, 0.20²)                 (13)
gᵖᵒᵗₜ = 1.80 + 0.70·(gᵖᵒᵗₜ₋₁ − 1.80) + εᵍₜ,   εᵍ ~ N(0, 0.25²)     (14)
```

Все процессы стационарны (|ρ| < 1) и стартуют из безусловного распределения:

```
x₀ ~ N(0, σ²/(1−ρ²))
```

Поэтому отдельный burn-in для них не нужен; общий burn-in 60 кварталов устраняет влияние начальных условий эндогенного блока.

### 3.7. Потенциальный и фактический выпуск

```
log Y*ₜ = log Y*ₜ₋₁ + gᵖᵒᵗₜ / 400                                    (15)
log Yₜ  = log Y*ₜ + xₜ / 100                                          (16)
```

Деление на 400 переводит годовой процентный темп в квартальный логарифмический прирост: `g/100` процентов в год = `g/400` логарифмических пунктов в квартал. Деление на 100 в (16) переводит разрыв из процентных пунктов в логарифмические.

### 3.8. Производные ряды

| Ряд | Формула | Примечание |
| --- | --- | --- |
| `gdp_growth` | 400·(log Yₜ − log Yₜ₋₁) | SAAR, % |
| `price_index` | 100·exp(Σₛ≤ₜ ln(1 + πₛ/400)) | индекс цен |
| `inflation_yoy` | 100·(Pₜ/Pₜ₋₄ − 1) | г/г, % |
| `real_policy_rate` | iₜ − πᵧₒᵧₜ | ex post, % |
| `real_gdp` | exp(log Yₜ) | уровень |
| `gdp_index` | 100·exp(log Yₜ − log Y₀) | ребейз к 100 |
| `potential_gdp_index` | 100·exp(log Y*ₜ − log Y₀) | ребейз к 100 |
| `recession` | 1{gdp_growth < 0} | индикатор |

## 4. Порядок вычисления и временная диаграмма

На каждом квартале `t`:

```
i_{t−1}, π_{t−1}, x_{t−1}, η_{t−1}
        │
        ├─► (1) πᵉₜ
        ├─► (2) rᵉₜ
        ├─► (3) xₜ          ← x*ₜ, fₜ, oₜ, sₜ, εˣₜ
        ├─► (4) πₜ          ← x_{t−1}, oₜ, ε^πₜ
        ├─► (5)-(7) ηₜ, uᵍᵃᵖₜ, uₜ
        ├─► (8)-(9) iᵈᵉˢₜ, iₜ
        └─► (15)-(16) Y*ₜ, Yₜ
```

Такая последовательность гарантирует, что:

- политика реагирует на **текущие** инфляцию и разрыв выпуска (как в правиле Тейлора);
- спрос реагирует на **прошлую** ставку (лаг трансмиссии);
- инфляция реагирует на **прошлый** разрыв (лаг кривой Филлипса);
- безработица реагирует на **текущий** разрыв (закон Оукена);
- нет циклических зависимостей внутри квартала.

## 5. Калибровка

### 5.1. Философия калибровки

Значения подобраны так, чтобы:

1. воспроизводить правдоподобные циклические моменты (волатильность разрыва ≈ 0.7 п.п., инфляции ≈ 0.6 п.п., безработицы ≈ 0.3 п.п.);
2. обеспечивать стабильность системы и возврат к равновесию;
3. оставлять ELB страховочным механизмом, а не доминирующим режимом;
4. сохранять прозрачность: каждое число имеет экономическую интерпретацию.

Калибровка не является оценкой на реальных данных и не претендует на соответствие какой-либо конкретной стране или периоду.

## 6. Свойства и режимы

### 6.1. Нейтральное состояние

```
x = 0,  π = π*,  i = r* + π* = 2.75 %,  u = u* = 5.4 %
```

В отсутствие шоков система покоится в этой точке. Любое отклонение затухает со скоростью, определяемой ρₓ, α, ρ_i и обратными связями.

### 6.2. Нижняя граница ставки

Формально ELB встроена в правило (9): `iₜ = max{0.25, …}`. В baseline она **не связывает**: минимальная наблюдённая ставка — 1.43 %, то есть на всём интервале 1990Q1–2025Q4 желаемая ставка остаётся выше границы. ELB — страховочный механизм DGP, а не активный режим.

Если граница начнёт связывать (при более низкой инфляции, более глубоком спаде, иной калибровке или в сценарии), возникнут последствия:

- асимметрия: политика не может дополнительно смягчить условия;
- более глубокая и длительная рецессия;
- отрицательная реальная ставка ex post при низкой номинальной.

В текущей выборке эти эффекты не материализуются, поэтому при интерпретации IRF и сценариев не следует приписывать наблюдаемую асимметрию ELB.

### 6.3. Принцип Тейлора и стабильность

Линеаризованная система «выпуск–инфляция–ставка» стабильна, если реакция политики на инфляцию достаточно сильна (φ_π > 1 в сочетании с инерцией). При φ_π < 1 возможна самоподдерживающаяся инфляционная спираль. Baseline использует φ_π = 1.45, что даёт устойчивую динамику и реалистичные IRF.

### 6.4. Автокорреляция и HAC

Три источника персистентности:

1. эндогенная инерция (ρₓ = 0.68, α = 0.58, ρ_i = 0.78);
2. AR(1)-шоки (0.55–0.82);
3. серийно коррелированный остаток Оукена (ρ_η = 0.50).

Совокупный эффект — остатки, автокоррелированные в разной степени: наиболее заметно в уравнении Оукена (ACF(1) ≈ 0.45), умеренно в кривой Филлипса (≈ 0.12), практически незаметно в IS и правиле Тейлора. Именно поэтому HAC-ошибки с лагом 4 применяются ко всем уравнениям как стандартная страховка; для Оукена они критичны.

## 7. Соответствие DGP и оцениваемых уравнений

| DGP | Оцениваемое уравнение | Совпадение | Расхождение |
| --- | --- | --- | --- |
| (3) | `xₜ ~ xₜ₋₁ + rᵉₜ + fₜ + x*ₜ + sₜ` | точная спецификация | все регрессоры предопределены или экзогенны; OLS состоятелен, отклонение — выборочное |
| (4) | `πₜ ~ πₜ₋₁ + xₜ₋₁ + oₜ` | точная спецификация | константа поглощает π*(1−α); OLS состоятелен |
| (5)–(7) | `uᵍᵃᵖₜ ~ xₜ` | точная спецификация | остаток AR(1) независим от xₜ; OLS состоятелен, но неэффективен |
| (8)–(9) | `iₜ ~ iₜ₋₁ + πₜ + xₜ` | линейная часть | ELB и нелинейность max{} не учитываются; коэффициент при π — не φ_π, а (1−ρ_i)·φ_π ≈ 0.32 |

**Почему оценки близки к истине.** В IS-уравнении `rᵉₜ` **предопределена**: она зависит только от `iₜ₋₁` и `πₜ₋₁` и потому не коррелирована с `εˣₜ`. В кривой Филлипса `xₜ₋₁` и `oₜ` не коррелированы с `ε^πₜ`, а в законе Оукена `ηₜ` не коррелирован с `xₜ`, поскольку `ε^u` независим от `εˣ`. Поэтому OLS состоятелен во всех трёх уравнениях, а HAC-поправка нужна исключительно для корректных стандартных ошибок при автокоррелированных остатках.

В правиле Тейлора `ε^i` независим от `πₜ` и `xₜ`, поэтому классической simultaneity bias здесь тоже нет. В baseline нижняя граница не связывает (минимальная ставка 1.43 %), поэтому `max{}` не вносит цензурирования; отклонение оценки 0.335 от композитного коэффициента 0.319 — выборочное. В конфигурациях, где ELB связывает, OLS-линия описывает смесь режимов (Tobit-подобное смещение).

**Где оценки будут смещены.** В baseline — только конечная выборка и возможные пропущенные нелинейности. Если ELB начинает связывать, к ним добавляется цензурирование на нижней границе. HAC-ошибки не исправляют смещение спецификации: они корректируют только автокорреляцию и гетероскедастичность.

## 8. Сценарии

### 8.1. Базовая проекция

Старт — терминальное состояние выборки:

```
(x_T, π_T, i_T, uᵍᵃᵖ_T, x*_T, f_T, o_T, s_T, gᵖᵒᵗ_T)
```

Далее для h = 1…12:

1. экзогенные AR(1) продолжаются условно на последние значения;
2. эндогенный блок симулируется по (1)–(9);
3. шоки разыгрываются независимо по путям из калиброванных распределений.

1 500 траекторий; квантили 5/16/50/84/95 %.

### 8.2. Сценарий ужесточения

```
iᵈᵉˢₜ ← iᵈᵉˢₜ + offsetₕ,   offsetₕ = 1 п.п. при h ≤ 4, иначе 0
```

Оба сценария используют **одни и те же** массивы инноваций (common random numbers). Разность медиан:

```
Δy(h) = median[yᵗⁱᵍʰᵗ(h)] − median[yᵇᵃˢᵉ(h)]
```

Это модельный контрфактический эффект. Он **не** равен причинному эффекту в реальной экономике и **не** учитывает равновесные изменения ожиданий (ожидания в модели адаптивны и не реагируют на объявленный сценарий).

### 8.3. Почему не VAR-проекция

VAR-проекция была бы оценённой аппроксимацией с неопределённостью коэффициентов; сценарный анализ через DGP позволяет точно контролировать интервенцию и избежать проблемы Лукаса в её самой острой форме. VAR при этом сохраняется как независимая проверка динамических свойств.

## 9. Декомпозиция

Точная бухгалтерская идентичность:

```
xₜ = inertiaₜ + real_rateₜ + fiscalₜ + externalₜ + financialₜ + shockₜ
```

где

```
inertiaₜ    = ρₓ·xₜ₋₁
real_rateₜ  = −σᵣ·(rᵉₜ − r*)
fiscalₜ     = δ_f·fₜ
externalₜ   = δ_{x*}·x*ₜ
financialₜ  = −δ_s·sₜ
shockₜ      = εˣₜ
```

Сумма компонентов равна наблюдаемому разрыву с точностью до плавающей точки. Проверка: максимальная ошибка идентичности в baseline — `0.00e+00` п.п.

**Интерпретация.** Это не историческая декомпозиция шоков в смысле VAR: компоненты не ортогональны, а `real_rate` эндогенна. Водопад отвечает на вопрос «из чего алгебраически состоит текущий разрыв при данных коэффициентах», а не «какой шок вызвал движение».

## 11. Возможные расширения

- **Рациональные ожидания** с моделью обучения (constant-gain learning).
- **Кривая Филлипса с инфляционными ожиданиями** вместо лага инфляции.
- **Несколько лагов** в IS и PC.
- **Режимные переключения** (Markov switching) для рецессий.
- **Sign restrictions** вместо Холецкого для идентификации.
- **Байесовская оценка** с априорными распределениями на параметры.
- **Микрофундированный блок** с функцией полезности и Calvo-ценообразованием.

Каждое расширение должно сохранять главное свойство стенда: истина известна, идентичности проверяемы, результаты воспроизводимы.
